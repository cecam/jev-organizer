# Security reporting

Do not post API keys, private notes, or exploit details in a public issue.

If GitHub private vulnerability reporting is enabled, use the repository's **Security → Report a vulnerability** page. If that option is unavailable, open an issue titled “Private security contact requested” with no sensitive details so the maintainer can arrange a private channel.

There is no guaranteed response time. Security fixes are intended for the latest release. Report ordinary non-sensitive bugs through the bug report form.
